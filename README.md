# PawPal Companion Robot

A small physical companion robot built around an ESP32-S3, exploring how
product concepts such as companionship, training, and monitoring map onto
explicit modes, event rules, expressions, and screen output.

Work in progress. Hardware: ESP32-S3 DevKitC-1, ST7789 240x240 display,
TTP223 touch, MPU6050 IMU.
